# Data

This folder contains the dataset used in the analysis.

## File

`climber_df.csv` contains climber-level data, including country, sex, height, weight, age, climbing experience and maximum achieved climbing grade.

## Source

The data comes from the 8a.nu climbing logbook dataset originally published on Kaggle by David Cohen.

Dataset source:

https://www.kaggle.com/datasets/dcohen21/8anu-climbing-logbook

The original data is based on public climbing logbook data from 8a.nu.

## Notes

The dataset represents users of the 8a.nu platform, not the entire global population of climbers. Therefore, conclusions should be interpreted as trends within this specific climbing community.
