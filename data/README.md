# Data

This folder contains the dataset used in the analysis.

## File

`climber_df.csv` contains climber-level data used for sport climbing performance analysis.

## Source

The data comes from the `Climb Dataset` published on Kaggle.

Dataset source:

https://www.kaggle.com/datasets/jordizar/climb-dataset

## Notes

The dataset is used for educational and non-commercial exploratory data analysis. Conclusions should be interpreted as observations based on this dataset, not as causal claims about all climbers.
